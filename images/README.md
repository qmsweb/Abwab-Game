# مجلد الصور

كل صور اللعبة تُحفظ هنا بصيغة `jpg` أو `png` أو `webp`. لا يحتاج الكود لأي تعديل، فقط سمِّ الملفات بنفس المسارات المذكورة في ملفات البيانات داخل `data/`.

## ١) صور الشخصيات — `images/biographies/`

استخدم صورة مربعة أو رأسية بنسبة 3:4 تقريبًا. الإنشاء الحالي يتوقع:

| الملف | الشخصية |
| --- | --- |
| `ibn-khaldun.jpg` | ابن خلدون |
| `ibn-sina.jpg` | ابن سينا |
| `einstein.jpg` | ألبرت أينشتاين |
| `nazik-malaika.jpg` | نازك الملائكة |
| `tariq-ibn-ziyad.jpg` | طارق بن زياد |
| `mandela.jpg` | نيلسون مانديلا |

## ٢) صور الأمثال — `images/puzzles/`

كل سؤال في باب «الصور» يعرض صورتين أو ثلاثًا. الأسماء الحالية:

- `100-t1-1.jpg` و`100-t1-2.jpg` — اليد الواحدة لا تصفق
- `100-t2-1.jpg` و`100-t2-2.jpg` — القطة والجرس
- `200-t1-1.jpg` و`200-t1-2.jpg` — قطرة الماء والصخر
- `200-t2-1.jpg` و`200-t2-2.jpg` و`200-t2-3.jpg` — عصفور في اليد
- `300-t1-1.jpg` و`300-t1-2.jpg` و`300-t1-3.jpg` — الصبر مفتاح الفرج
- `300-t2-1.jpg` و`300-t2-2.jpg` و`300-t2-3.jpg` — الجبل والإنسان

> حتى تضيف صورة: ضع الملف بالاسم الصحيح، وستظهر تلقائيًا عند فتح السؤال. وإذا لم توجد الصورة يظهر بديل أنيق يعرض التلميح النصي بدلًا منها، فلا تتعطّل اللعبة.

## نصائح

- اضغط الصور قبل رفعها (العرض الموصى به 1200px كحد أقصى).
- تجنّب الصور التي تحتوي على نصوص عربية داخل الصورة إن أمكن، لتظل واضحة على الشاشة.
- لا تستخدم روابط خارجية؛ التطبيق يعمل دون اتصال بالإنترنت.
