# مجلد الصوت

كل مقاطع اللعبة الصوتية تُحفظ هنا بصيغة `mp3`. لا يحتاج الكود لأي تعديل، فقط ضع الملفات بالمسارات المذكورة في ملفات البيانات داخل `data/`، وستظهر داخل مشغل صوت المتصفح في صفحة السؤال.

## ١) الملفات التجريبية الحالية

| الملف | السؤال | الاستخدام |
| --- | --- | --- |
| `demo-general.mp3` | `general-m9` | لحن «عيد ميلاد سعيد» — باب الأسئلة العامة |
| `demo-biographies.mp3` | `bio-m9` | مقطوعة «من أجل إليزه» — باب السيرة الذاتية |

> الملفان مُولّدان تجريبيًا للتحقق من عمل المشغل، ويمكن حذفهما أو استبدالهما بأي ملفات `mp3` حقيقية.

## ٢) إضافة سؤال صوتي

```js
{
  id: 'general-m9',
  difficulty: 2,
  type: 'audio',
  audio: 'audio/اسم-الملف.mp3',
  audioLabel: 'مقطع صوتي',      // عنوان اختياري يظهر فوق المشغل
  hint: 'تلميح اختياري يظهر أسفل المشغل',
  question: 'نص السؤال',
  answer: 'نص الإجابة'
}
```

- يمكن استخدام `audios` بدل `audio` لعرض أكثر من مقطع في السؤال نفسه:
  `audios: [ { src: 'audio/a.mp3', label: 'المقطع الأول' } ]`
- يمكن إضافة `audio` إلى سؤال صور عادي، فيظهر الصوت أسفل الصور في البطاقة نفسها.
- إذا لم يوجد الملف أو تعذّر تشغيله يظهر بديل أنيق برسالة توضيحية، ولا تتعطل اللعبة.
- استخدم ملفات `mp3` قصيرة (١٠–٣٠ ثانية) وبحجم صغير لتبقى اللعبة سريعة على GitHub Pages.

## نصائح

- لا تستخدم روابط خارجية؛ التطبيق يعمل دون اتصال بالإنترنت.
- اضغط الملفات بمعدل `64–96 kbps` أحادي القناة لتقليل الحجم.
- تأكد من أن اسم الملف يطابق الحقل `audio` تمامًا (بما في ذلك حالة الأحرف والامتداد).
