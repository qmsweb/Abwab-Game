# أبواب — لعبة أسئلة تنافسية بين فريقين

لعبة مسابقات عربية بين فريقين يديرها مذيع (Game Master) على الشاشة. تطبيق ثابت بالكامل: HTML + CSS + JavaScript فقط، بلا خادم أو قاعدة بيانات أو أي طلب شبكة، جاهز للعمل على GitHub Pages.

## طريقة اللعب

1. من صفحة الهبوط `index.html` اضغط **ابدأ اللعب الآن** للانتقال إلى اللعبة في `game.html`.
2. من الواجهة الرئيسية للعبة اضغط **بدء اللعبة**.
3. اكتب اسم كل فريق واختر أيقونته من نافذة «الفريقان المتنافسان».
4. اختر سؤالًا من اللوحة؛ يُفتح في صفحة مستقلة مع عداد تصاعدي للعرض فقط.
5. اضغط **عرض الإجابة** ثم أسند النقاط لأحد الفريقين أو «لا أحد».

## طريقة التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا بسيطًا:

```bash
npx serve .
```

> ملاحظة: تحميل الصور النسبية عبر `file://` قد يمنع ظهورها في بعض المتصفحات؛ التشغيل عبر خادم محلي أو GitHub Pages يضمن عمل كل شيء.

## بنك الأسئلة والتوزيع التلقائي

كل باب يحتوي الآن **بنك أسئلة** كبيرًا (24 سؤالًا في كل باب، 120 سؤالًا إجمالًا)، موزّعًا على ثلاث درجات صعوبة:

| الحقل في البيانات | المستوى على اللوحة |
| --- | --- |
| `difficulty: 1` | 100 نقطة — سهل |
| `difficulty: 2` | 200 نقطة — متوسط |
| `difficulty: 3` | 300 نقطة — صعب |

عند أول تشغيل أو عند بدء لعبة جديدة، يختار المحرك تلقائيًا:

- سؤالين من كل مستوى في كل باب: واحد للفريق الأول وواحد للفريق الثاني.
- 5 أبواب × 3 مستويات × سؤالين = **30 سؤالًا** على اللوحة، بإجمالي **6000 نقطة**.
- لا يتكرر السؤال نفسه في اللوحة الواحدة؛ ويُتحقق من تكرار المعرّف ونص السؤال والإجابة معًا.
- التوزيع يُحفظ في `localStorage`، فإعادة تحميل الصفحة لا تغيّر أسئلة اللوحة الحالية.
- عند بدء لعبة جديدة يُسحب توزيع جديد، مع تفضيل أسئلة لم تظهر في اللوحة السابقة إن كان البنك يتسع لذلك.
- إن كان بنك مستوى ما ناقصًا، يكمل المحرك من مستويات الباب الأخرى تلقائيًا مع تسجيل تنبيه في وحدة التحكم.

### إضافة أسئلة جديدة

أضف كائنًا جديدًا إلى مصفوفة `bank` في ملف الباب المطلوب:

```js
{
  id: 'general-e9',        // معرّف فريد لا يتكرر
  difficulty: 1,           // 1 سهل / 2 متوسط / 3 صعب
  type: 'text',            // 'text' أو 'image' أو 'images'
  question: 'نص السؤال',
  answer: 'نص الإجابة',
  hint: 'تلميح اختياري',
  image: 'images/biographies/example.jpg',          // لصورة واحدة
  images: [ { src: '...', alt: '...', hint: '...' } ] // لعدة صور
}
```

- `id` إلزامي وفريد على مستوى المشروع كله.
- `difficulty` هو ما يحدد المستوى تلقائيًا. يمكن استخدام `level: 1/2/3` أو `points: 100/200/300` بدلًا منه.
- لا تحتاج إلى كتابة `owner` أو `points` في كل سؤال؛ المحرك يوزّع الفريق والنقاط تلقائيًا حسب الزر.
- أي سؤال مكرر (نفس المعرّف أو نفس السؤال والإجابة) يُتجاهل تلقائيًا مع تنبيه في وحدة التحكم.

## روابط الصفحات داخل اللعبة (Hash Routing)

لكل صفحة معرّف مستقل في عنوان المتصفح داخل `game.html`، فلا يعتمد التنقل على «آخر موضع» محفوظ:

| الصفحة | الرابط |
| --- | --- |
| الرئيسية | `game.html#/` |
| لوحة اللعب | `game.html#/board` |
| سؤال محدد | `game.html#/q/<question-id>` مثل `game.html#/q/general-e1` |

- فتح أي رابط مباشرةً يفتح صفحته؛ وتحديث الصفحة يبقيها كما هي لأن الرابط هو المرجع.
- زرا الرجوع والتقدّم في المتصفح يعملان بين الصفحات، ويُعاد التوجيه إلى اللوحة تلقائيًا إذا كان السؤال المطلوب قد لُعب أو لم يعد ضمن اللوحة الحالية.
- لأن كل جهاز قد يحصل على توزيع مختلف، فإن روابط الأسئلة تعمل على الجهاز/اللعبة المحفوظة نفسها.
- تُحفظ النقاط والأسماء والأيقونات والأسئلة الملعوبة وتوزيع اللوحة فقط، ولا تُحفظ الصفحة المفتوحة سابقًا.

## القواعد المطبّقة

- واجهة رئيسية بشعار نصي في المنتصف وزرّي «بدء اللعبة» و«كيفية اللعب».
- نافذة إعداد الفريقين: اسم كل فريق وأيقونته (أيقونتان مختلفتان).
- لوحة نتائج ثابتة دائمًا مع اسمين قابلين للتعديل.
- صفحة سؤال مستقلة مع عداد تصاعدي للعرض فقط، تعود تلقائيًا للوحة بعد إسناد النقاط.
- ٥ أبواب × ٦ أزرار = ٣٠ سؤالًا، بإجمالي ٦٠٠٠ نقطة على اللوحة؛ ٣٠٠٠ نقطة مخصّصة لكل فريق، وقد يكسب الفريق أكثر منها إذا فاز بأسئلة الفريق الآخر.
- توزيع تلقائي يحترم الصعوبة: 100 سهل، 200 متوسط، 300 صعب، بلا تكرار في اللوحة.
- اللعب بالتناوب: زر «تبديل الدور» يمنح المذيع تحكمًا يدويًا كاملًا.
- إسناد السؤال: الفريق الأول / الفريق الثاني / لا أحد. الإسناد نهائي مباشرةً بعد العودة للوحة، ويظهر زر «تراجع عن آخر إسناد» في نافذة نهاية اللعبة فقط.
- **اللحاق:** فريق أنهى أسئلته الـ١٥ وهو متأخر يُفتح له أسئلة الفريق الآخر المتبقية (معلّمة بـ«لحاق»).
- **الفوز:** عند لعب كل الأسئلة، أو عند حسم الفارق رياضيًا (`الفارق > النقاط المتبقية`).
- حفظ تلقائي للنتائج والأسماء والأيقونات وتوزيع الأسئلة في `localStorage`، مع زر «لعبة جديدة» لتصفير النقاط وسحب توزيع جديد. الصفحة المفتوحة لا تُحفظ: معرّفها في الرابط هو المرجع.

## صفحة الهبوط

- صفحة تسويقية عربية RTL في `index.html` مستوحاة من تنظيم صفحات الألعاب الجماعية: شريط علوي، واجهة ترحيبية، أرقام اللعبة، الأبواب الخمسة، معاينة للوحة، خطوات اللعب، ودعوة للبدء.
- الحركات خفيفة وبلا مكتبات: ظهور تدريجي عند التمرير بـ `IntersectionObserver`، عدّادات للأرقام، عناصر عائمة، وقائمة جوال كاملة.
- تحترم `prefers-reduced-motion`، وتعمل بلا JavaScript (يظهر المحتوى كاملًا).
- كل الأزرار التي تبدأ اللعب تنتقل إلى `game.html`، وكل الأصول محلية بلا أي CDN.

## النشر على GitHub Pages

1. ارفع محتويات المشروع إلى المستودع (المجلد الجذر).
2. من إعدادات المستودع: **Pages → Build and deployment → Source: Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/ (root)` ثم احفظ.

كل المسارات نسبية، لذا يعمل التطبيق من أي مسار فرعي.

## ملاحظات

- الخطوط محلية بالكامل (`fonts/Elgharib-*.ttf`) ولا توجد أي روابط CDN.
- الألوان مطابقة لـ `DESIGN.md`: `#11001C` / `#290025` / `#35012C` / `#3A015C` / `#4F0147` ونصوص بيضاء.
- صفحة الهبوط تستخدم نسختين محسّنتين من الشعارات (`textlogo-640.png` و`logo-400.png`) لتقليل حجم التحميل، بينما تبقى النسخ الأصلية للعبة وللاستخدام عالي الدقة.
- إذا حُذف شعار المطور `logo/jassim.png` يظهر بديل نصي أنيق تلقائيًا بدلًا منه.
- عند تغيير بنك الأسئلة تغييرًا جذريًا قد لا يجد المحرك التوزيع المحفوظ، فيعيد توزيع لوحة جديدة ويصفّر تقدّم اللعبة المحفوظة تلقائيًا مع إبقاء أسماء الفريقين وأيقوناتهما.
