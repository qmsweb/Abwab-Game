# جيم — مسابقة الأبواب الخمسة

لعبة مسابقات عربية بين فريقين يديرها مذيع (Game Master) على الشاشة. تطبيق ثابت بالكامل: HTML + CSS + JavaScript فقط، بلا خادم أو قاعدة بيانات أو أي طلب شبكة، جاهز للعمل على GitHub Pages.

## طريقة التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا بسيطًا:

```bash
npx serve .
```

> ملاحظة: تحميل الصور النسبية عبر `file://` قد يمنع ظهورها في بعض المتصفحات؛ التشغيل عبر خادم محلي أو GitHub Pages يضمن عمل كل شيء.

## بنية المشروع

```
index.html              هيكل الواجهة والنوافذ (RTL)
style.css               كل التنسيقات والتصميم المتجاوب
script.js               منطق اللعبة (الحالة، الأدوار، النقاط، اللحاق، الفوز)
data/
  general.js            باب الأسئلة العامة
  biographies.js        باب السيرة الذاتية
  letters.js            باب الحروف
  images.js             باب الصور
  arabic.js             باب اللغة العربية
images/                 مكان الصور (انظر images/README.md)
fonts/                  خط Elgharib المحلي (Regular / Medium / Bold)
logo/                   شعارات الهوية
```

كل باب في ملف مستقل داخل `data/`، ويُحمَّل بالترتيب عبر وسوم `<script>` في نهاية `index.html`. لإضافة باب جديد: أنشئ ملفًا بنفس النمط، ثم أضف وسم `<script>` له قبل `script.js`.

## بنية بيانات السؤال

```js
{
  id: 'general-100-t1',   // معرّف فريد (لا تغيّره بعد بدء لعبة محفوظة)
  points: 100,            // 100 / 200 / 300
  owner: 1,               // الفريق صاحب السؤال: 1 أو 2
  type: 'text',           // 'text' أو 'image' أو 'images'
  question: 'نص السؤال',
  answer: 'نص الإجابة',
  hint: 'تلميح اختياري',
  image: 'images/biographies/ibn-sina.jpg',        // لصورة واحدة
  images: [ { src: '...', alt: '...', hint: '...' } ] // لعدة صور
}
```

كل باب يجب أن يحتوي **٦ أسئلة** (٣ لكل فريق). لا يتطلب الكود ترتيبًا معينًا داخل الملف؛ اللوحة ترتّب الأزرار حسب النقاط والفريق تلقائيًا.

## القواعد المطبّقة

- لوحة نتائج ثابتة دائمًا مع اسمين قابلين للتعديل.
- ٥ أبواب × ٦ أسئلة = ٣٠ سؤالًا، بإجمالي ٦٠٠٠ نقطة على اللوحة؛ ٣٠٠٠ نقطة مخصّصة لكل فريق، وقد يكسب الفريق أكثر منها إذا فاز بأسئلة الفريق الآخر.
- اللعب بالتناوب: زر «تبديل الدور» يمنح المذيع تحكمًا يدويًا كاملًا.
- إسناد السؤال: الفريق الأول / الفريق الثاني / لا أحد، مع زر «تراجع» لتصحيح الإسناد الأخير.
- **اللحاق:** فريق أنهى أسئلته الـ١٥ وهو متأخر يُفتح له أسئلة الفريق الآخر المتبقية (معلّمة بـ«لحاق»).
- **الفوز:** عند لعب كل الأسئلة، أو عند حسم الفارق رياضيًا (`الفارق > النقاط المتبقية`).
- حفظ تلقائي للنتائج والأسماء في `localStorage`، مع زر «لعبة جديدة» لتصفير النقاط.

## النشر على GitHub Pages

1. ارفع محتويات المشروع إلى المستودع (المجلد الجذر).
2. من إعدادات المستودع: **Pages → Build and deployment → Source: Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/ (root)` ثم احفظ.

كل المسارات نسبية، لذا يعمل التطبيق من أي مسار فرعي.
